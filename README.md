# Проект веб-приложения сервиса рассылки сообщений
## Описание:
**Данное приложение предполагает создание веб-приложения сервиса рассылки сообщений.**
## Цель проекта:
Реализовать приложение, которое позволяет пользователям управлять рассылками сообщений для клиентов.
## Установка:
1. Клонируйте репозиторий:
```python
https://github.com/PetrMaev/message_service.git
```
```python
git@github.com:PetrMaev/message_service.git
```
2. Установите зависимости:
```python
poetry install
```
## Наполнение данными базы данных:
Для наполнения данными базы данных используйте кастомные команды и фикстуры
## Использование:
Для запуска программы введите в терминале следующую команду:
```python
python manage.py runserver
```
## В проекте реализованы:
1. Регистрация и аутентификация пользователей
2. Функциональность для создания, просмотра, редактирования и удаления рассылок, а также отправки сообщений по требованию.
3. Для каждой попытки отправки рассылки сохраняются следующие данные: дата и время попытки, статус (успешно / не успешно), ответ почтового сервера.
4. Статистика и отчеты
